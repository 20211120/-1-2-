南航评论区 · 一键启动说明
=====================================

一、在别的电脑上使用（不需要装 Python）
1. 把整个"机器学习大作业"文件夹拷到目标电脑（任意盘符、任意路径都行）
2. 进入 软件 文件夹，双击：
     打开-电脑版.lnk   → 自动启动服务并打开电脑版页面
     打开-手机版.lnk   → 自动启动服务并打开手机版（窄窗口）
   也可以直接双击 软件\南航评论区.exe（效果同电脑版）
   或双击 启动-电脑版.bat / 启动-手机版.bat（不依赖快捷方式，最稳）
3. 关闭：关闭浏览器窗口即可。若需彻底停止，任务管理器里结束"南航评论区.exe"

二、换电脑后快捷方式打不开怎么办
双击 软件\修复快捷方式.bat，会自动重建两个快捷方式。

三、注意
- 软件\_internal 文件夹是 exe 的运行时依赖，不要删除、不要单独移动
- 软件\封图.ico 是图标文件，修复快捷方式时要用
- data.db、uploads、campus-map、手机版 必须和 软件 文件夹保持现在的相对位置

四、修改内容（不影响换电脑使用）
- 改页面（文字/样式/布局）：直接改 campus-map\frontend\ 或 手机版\ 里的文件，刷新页面即可生效
- 改后端（接口/数据逻辑）：改 campus-map\backend\app.py
  · 本机装了 Python 时，启动脚本优先用 Python 跑源码（改完重启即生效）
  · 只想要 exe 模式：双击 软件\南航评论区.exe

五、只有改了后端、又想让"没装 Python 的电脑"用上新逻辑时，才需要重新打包
1. 安装 Python 3.10+
2. pip install flask flask-cors pyinstaller
3. 在 campus-map\backend 目录运行：
   pyinstaller --onedir --noconfirm --name 南航评论区 --icon "..\..\软件\封图.ico" app.py
4. 把 dist\南航评论区\南航评论区.exe 和 _internal 文件夹复制到 软件\ 覆盖

六、端口说明
服务固定使用本机 5000 端口（http://127.0.0.1:5000/ 电脑版，/m/ 手机版），
只监听本机，不会触发防火墙弹窗。
七、界面行为说明
- 双击 打开-电脑版.lnk / 打开-手机版.lnk：黑窗口会"一闪即自动隐藏"，随后自动弹出页面
- 页面已经打开过时，再双击快捷方式不会重复启动，只会再打开一个页面窗口
- 想彻底停止后台服务：双击 软件\停止服务.bat（或在任务管理器结束"南航评论区.exe"）
- 若页面没自动弹出：手动在浏览器打开 http://127.0.0.1:5000/ （手机版 /m/）
- 启动日志写在 根目录\_startup.log（排查用，可随时删除）
