## 修复：地图页登录弹窗无法输入
- 用户反馈登录弹窗填不了账号密码。用无头 Edge + puppeteer-core（系统 Edge，免下 Chromium）实测定位：腾讯地图 GL JS 会向 `#map` 注入 `z-index:1000` 的绝对定位交互层，因 `#map` 未创建层叠上下文，该层参与根层叠、盖住登录弹窗（z-200），鼠标点击落在遮挡层上
- 修复：`#map { z-index:0 }` 创建层叠上下文禁锢 TMap 内部层级；`.auth-modal` z-index 200→10000；map.html `.modal` 100→9000；`.fab/.route-info/.choose-tip` 6→1001（否则标注按钮/路线浮窗在地图交互层下也点不到）
- 验证：elementFromPoint 命中 authUser、鼠标+键盘真实输入成功、fab 与楼层 SVG 可点击，截图 login_fixed.png
- 经验：agent-browser 安装超时（官方源），改用 puppeteer-core（npmmirror 源 7 秒装好）+ 系统 Edge 是 Windows 下轻量浏览器验证路径
