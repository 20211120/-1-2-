# 南航评论区 · 校园一站式社区平台

机器学习课程设计 · 自定义方向（以南航将军路校区为原型）

平台包含四大模块：**校园地图**、**失物招领**、**校园评论**、**二手市集**，共同使用同一套后端 API 与机器学习引擎。

## 功能模块

### 🗺️ 校园地图
- 腾讯地图 GL JS 真实底图，12 个校园 POI 按类别着色标记（图书馆/教学楼/食堂/体育/宿舍…）
- **精确到教室**：教学楼可打开自绘 SVG 楼层平面图，点击教室（1-101 ~ 1-210）单独评论
- **实时步行导航**：浏览器定位（WGS84→GCJ02 坐标转换）或点击地图选起点，规划步行路线并显示分步指引
- **地点备注**：可为任意地点添加备注，选择 **公开**（所有人可见）或 **私密**（仅自己可见）
- **地点评论**：AI 自动情感分析 + 标签分类，聚合出好评率与热门标签

### 🎒 失物招领（含 ML① 智能匹配）
- 发布「寻物」或「招领」信息，填写地点（关联地图 POI 或手填）、详细描述、联系方式
- 支持**上传失物图片**，卡片流展示，点击查看详情与联系方式
- 发帖人可一键标记「已解决」，发布时 AI 自动打标签
- **智能匹配**：每条新信息发布后自动与反向类型（寻物 ↔ 招领）的历史信息比对，
  按「文本相似度 + 物品类别 + 地点 + 时间 + 特征词」加权打分，≥ 0.60 判定为高置信匹配
- **互相推送**：高置信匹配会给**双方各自**推送一条站内通知，
  通知里写明相似度与匹配理由，点击直接打开对方那条信息

### 🔔 站内通知中心（ML① 的推送落地）
- 顶栏铃铛显示未读数，30 秒轮询刷新；点开是通知列表，可「全部已读」
- 每条通知给出匹配理由（同属「钥匙」类物品、地点相同、相差 5.5 小时…）、
  相似度百分比、被匹配信息的类型与标题，点击跳转到失物招领详情

### 💬 校园评论
- 自由发帖、评论互动、点赞、关键词搜索
- **支持删帖 / 删评**（楼主删自己的帖子与帖下评论、作者删自己的评论，见下方「内容删除」）
- 发帖时 AI 自动识别情绪倾向并打标签（如「人多」「适合自习」）

### 🛒 二手市集（含 ML③ 语义检索）
- 发布「出售」或「求购」信息，支持分类（书籍/电子/生活/运动/其他）、定价、上传实物图片、留联系方式
- 卡片流展示 + 分类/类型筛选，点击查看详情与联系方式
- 发布人可一键标记「已成交」，发布时 AI 自动打标签
- **语义检索**（默认开启，可切换「精确匹配」做对比）：
  搜「笔记本」能搜出电脑、搜「单车」能搜出自行车、搜「机械健盘」（错别字）也能命中键盘；
  结果按相关度排序并标出「语义命中」的词

### 🛡️ ML② 内容安全（全站生效，命中即拦截）
- 覆盖范围：论坛发帖/评论、地点评论、地图备注、失物招领、二手市集发布
- 识别四类：正常内容 / 垃圾广告 / 引战挑事 / 不文明用语
- **判定为不良内容就直接拦截**：返回 400 并说明原因（命中特征、风险分），
  **不给发表、不进入任何人工审核队列**；每次拦截写入 `moderation_logs` 作为处置记录
- 判定线 0.50 的标定（详见 `ml_eval_report.txt`）：164 条标注语料中正常内容 risk
  最高只有 0.282（余量 0.218），取 0.50 时广告召回 0.95、不文明召回 0.97、
  引战召回 0.78，正常误伤 0/60
- 上下文感知：二手市集与失物招领里「留微信 / 留 QQ」属正常行为，相关规则权重
  降到 1/4、模型的广告概率再压 0.8，只有刷单、代写、贷款、办证等强风险信号才拦截；
  「吐槽 / 举报别人发广告」也能识别出来并放行

### 🗑️ 内容删除（帖子 + 评论）
- **帖子**：楼主可删自己的帖子（连带删除该帖下所有评论，不留孤儿数据）
- **论坛评论**：评论作者本人可删；帖子楼主可删自己帖子下的任何评论
- **地点评论**：只能删自己发的（匿名发布的评论没有可验证作者，无法删除）
- **备注评论**：评论作者本人可删；备注作者（楼主）可删自己备注下的评论
- 删除前都有二次确认；越权删除一律 403，未登录 401；前端按权限渲染入口，服务端再校验一次

## 机器学习设计（答辩讲解要点）

三项能力全部用**纯 Python** 实现（只用标准库），不依赖 sklearn / jieba / numpy，
因此 `exe` 模式下无需任何环境即可运行，模型在进程内秒级训练完成。

### ML① 失物招领智能匹配（`backend/ml/matcher.py`）

| 特征 | 权重 | 说明 |
|---|---|---|
| 文本相似度 | 0.40 | 字级 2-3gram TF-IDF 余弦，抗改写与错别字 |
| 物品类别一致度 | 0.26 | 领域词典抽取物品类型（钥匙/校园卡/耳机…）；类型冲突直接乘 0.40 否决 |
| 地点一致度 | 0.14 | 优先比对地图 POI，其次地点串的字符二元组 Jaccard |
| 时间接近度 | 0.08 | `1/(1+Δt/36h)` 衰减 |
| 特征词重合度 | 0.12 | 颜色 / 挂件 / 图案等区分性特征（"飞机挂件""黑色"） |
| 证据加成 | +0.16 | 类别互相印证、类别与地点同时吻合、区分性特征吻合 |

- 满分为 1：≥ 0.60 高置信（互相推送），0.38 ~ 0.60 存为「可能相关」不打扰用户
- 离线评估：20 对人工标注样本（10 正 / 10 负）准确率 1.00、精确率 1.00、召回率 1.00

### ML② 内容安全识别（`backend/ml/moderation.py`）

- **规则层**：面向校园场景整理的 30+ 条正则，噪声或（noisy-OR）合并，高精度低召回
  （语料上触发时精确率 1.00、召回率 0.75）
- **统计层**：字符 1-2gram TF-IDF 的**类质心（Rocchio）分类器**，
  训练语料为人工标注的 **164 条**校园短文本
- **对比实验**：同语料同特征下，朴素贝叶斯 5 折准确率仅 **0.4024**
  （字级特征太稀疏，未登录特征的平滑概率主导打分），换成类质心后升到 **0.8537**、
  宏平均 F1 **0.8374**；NB 实现保留在模块内作为基线
- 两层取并集（`max(规则分, 模型概率)`），再按阈值分三段动作

### ML③ 二手市集语义检索（`backend/ml/semantic.py`）

查询先做三种扩展：

| 扩展来源 | 例子 | 权重 |
|---|---|---|
| 同义词表（27 组） | 笔记本 → 电脑 / 台式机 / 主机 | 0.75 |
| 主题上位词（17 类，含一跳同义扩展） | 音乐器材 → 吉他 / 尤克里里 / 电子琴 | 0.60 |
| 语料共现学习（PMI） | 键盘 → 鼠标、相机 → 三脚架（从全站文本统计，非写死） | 0.50 |

再用四个通道融合打分：

| 打分通道 | 权重 |
|---|---|
| 词级 TF-IDF 余弦（含扩展词） | 0.30 |
| 词级覆盖率（可替换词被命中的比例） | 0.32 |
| 字级覆盖率（IDF 加权，未登录 n-gram 降权 → 抗错别字） | 0.22 |
| 字级余弦 | 0.06 |
| 字面命中加成（命中标题 +0.12 / 描述 +0.06） | — |

- 离线评估：13 条人工标注查询，Recall@1 = 1.00、MRR = 1.00；
  同集合下关键词精确匹配只有 Recall@1 = 0.15
  （标注集刻意覆盖同义词 / 错别字 / 大类 / 自然语言四类查询）

### 评估与自检脚本

| 脚本 | 作用 |
|---|---|
| `backend/ml/eval_all.py` | 三项能力的离线评估，输出 `backend/ml_eval_report.txt` |
| `backend/test_ml_features.py` | 三项能力的全链路自检（需服务已启动），34 项断言 |
| `backend/test_platform.py` | 原有平台回归自检 |
| `backend/ml/experiment.py` | 早期情感分析特征方案对比（课程素材） |

## 项目结构

```
campus-map/
├── backend/
│   ├── app.py            # Flask API：地图/备注/失物招领/论坛/市集/认证/通知/统计
│   ├── test_platform.py  # 原有平台全链路自检
│   ├── test_ml_features.py # 三项 ML 能力全链路自检
│   ├── ml_eval_report.txt  # 离线评估报告（由 ml/eval_all.py 生成）
│   ├── ml/
│   │   ├── textutil.py   # 纯 Python 文本工具（归一化/字 n-gram/TF-IDF/词典切词）
│   │   ├── matcher.py    # ML① 失物招领智能匹配
│   │   ├── moderation.py # ML② 垃圾广告/引战/不文明识别 + 标注语料
│   │   ├── semantic.py   # ML③ 二手市集语义检索
│   │   ├── eval_all.py   # 三项能力离线评估
│   │   ├── corpus.py     # 早期情感分析语料（课程素材，线上不加载）
│   │   ├── sentiment.py  # 早期情感/标签模型（课程素材，线上不加载）
│   │   └── experiment.py # 早期特征方案对比实验
│   ├── uploads/          # 失物图片（运行时生成）
│   └── data.db           # SQLite（首次运行自动建库 + 种子数据）
└── frontend/
    ├── index.html        # 平台门户首页
    ├── map.html          # 校园地图模块
    ├── lostfound.html    # 失物招领模块
    ├── forum.html        # 校园评论模块
    ├── common.css / common.js   # 平台导航、登录态、API 封装
```

## 启动方式

```bash
cd backend
pip install flask flask-cors      # 仅两个依赖；三项 ML 能力零第三方依赖
python app.py                     # http://127.0.0.1:5000
```

浏览器打开 `http://127.0.0.1:5000/` 进入电脑版，`/m/` 进入手机版，
顶部导航可在四大模块间切换。未启动后端时，各页面顶部会出现黄色提示条。

> 地图采用腾讯地图 GL JS 密钥代理模式，前端零密钥，符合地图合规要求。
> POI 坐标为 GCJ-02 近似值，可在 `app.py` 的 `SEED_POIS` 中校准。

## API 速览

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | /api/auth/register、/api/auth/login | 注册 / 登录（返回 token） |
| GET | /api/pois?q=&category= | 地点列表（含统计） |
| POST | /api/pois/{id}/comments | 发表地点评论（含内容安全判定） |
| DELETE | **/api/pois/{id}/comments/{cid}** | 删除地点评论（仅作者本人） |
| GET/POST | /api/pois/{id}/notes | 备注（公开/私密权限过滤） |
| DELETE | /api/notes/{id} | 删除自己的备注 |
| DELETE | **/api/map_notes/{id}/comments/{cid}** | 删除备注评论（作者本人 / 备注作者） |
| GET/POST | /api/lostfound | 失物招领列表（含已匹配数）/ 发布（发布即匹配） |
| GET | **/api/lostfound/{id}/matches** | 某条信息的智能匹配结果（相似度 + 理由） |
| POST | /api/lostfound/{id}/resolve | 标记已解决 |
| GET | **/api/notifications** | 我的站内通知 + 未读数 |
| POST | **/api/notifications/read** | 标记已读（传 ids 或全部） |
| GET | **/api/moderation/logs** | 内容安全处置记录 + 模型指标（仅本机 + 需登录） |
| GET/POST | /api/posts | 论坛帖子 / 发帖（含内容安全判定） |
| DELETE | **/api/posts/{id}** | 删除自己的帖子（连带删除帖下评论） |
| POST | /api/posts/{id}/comments、/like | 评论 / 点赞 |
| DELETE | **/api/posts/{id}/comments/{cid}** | 删除论坛评论（作者本人 / 帖子楼主） |
| GET/POST | /api/market | 二手市集列表（LIKE 精确匹配）/ 发布 |
| GET | **/api/market/search?q=&mode=semantic\|keyword** | 语义检索（带相关度与扩展说明） |
| GET | /api/stats | 全站统计 + ML 指标（匹配数、拦截数、模型准确率） |

## 验证方式

```bash
cd campus-map/backend
python app.py                  # 终端 1：启动服务

# 终端 2
python -m ml.eval_all          # 离线评估三项能力 → ml_eval_report.txt
python test_ml_features.py     # 四项能力全链路自检（46 项断言）→ ml_features_test.log
python test_platform.py        # 原有平台回归自检 → platform_test.log
```
